How it Works

1. 入力して「追加」を押すと...

JavaScript（フロントエンド）が起動します。
fetch('/todos', { method: 'POST', ... }) を使い、入力されたテキストをGoサーバーへ送信します。

2. 裏側のGoサーバーが受け取る

Goのルーティング機能が、送られてきたデータを受け取ります。
JSONデータをGoの構造体に変換し、データベース（次のステップで設置！）へ保存します。

3. Goが結果をJSONで返す

保存が完了すると、Goは最新のTodoリストを
json.NewEncoder(w).Encode(todos) でJSON形式のテキストに変換し、フロントエンドに返します。

4. フロントエンドが画面を描画

JavaScriptが受け取ったJSONデータを解析し、
新しいHTML要素を組み立てて画面を更新します。
これが、にゅるっとした動きとともに表示されるTodoの正体です！
